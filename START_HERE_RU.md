# Начало работы в PyCharm (Windows)

## 1. Что уже сделано

Первая версия сайта для исследования диабетической ретинопатии: регистрация, каталог снимков, поиск по названию и источнику, фильтр по степеням 0–4, CRUD, загрузка JPG/PNG до 10 МБ, PostgreSQL, API FastAPI и тесты.

**Важно:** нейросеть ещё не обучена, поэтому загрузка картинки НЕ вычисляет диагноз или степень ДР. Файл модели опухолей головного мозга в проект не включён.

## 2. Открыть проект

1. Распакуй `diabetic-retinopathy-system-starter.zip` в удобную папку, например `C:\Projects\diabetic-retinopathy-system`.
2. Запусти **PyCharm → File → Open** и выбери папку `diabetic-retinopathy-system`.
3. Для запуска всего приложения потребуются **Docker Desktop (запущенный)** и доступ в интернет при первой сборке для загрузки зависимостей/образов. По методичке желательно Python 3.12+ и Node.js 24 LTS для работы вне Docker.

## 3. Настроить .env

Открой вкладку Terminal в PyCharm и выполни в корне проекта:

```powershell
Copy-Item .env.example .env
```

Открой файл `.env` и задай собственные безопасные значения `POSTGRES_PASSWORD` и `SECRET_KEY`. **Никогда не публикуй `.env` в GitHub.**

## 4. Запустить

```powershell
docker compose up --build
```

Первый запуск может занять несколько минут.

Открой в браузере:

- **http://localhost:3000** — веб-приложение.
- **http://localhost:8000/docs** — документация API.

Нажми **Регистрация**, придумай учебную учётную запись, войди и проверь страницы «Загрузка», «Каталог», «Справочник», «О модели».

## 5. Добавить демонстрационные данные

В новом терминале PyCharm, пока Docker работает:

```powershell
docker compose exec backend python -m scripts.seed
```

В каталоге появятся **30 синтетических текстовых записей**. Это не настоящие снимки и не размеченный медицинский датасет.

## 6. Проверка функциональности

- Создай карточку вручную с названием `Fundus sample 001`, источником `Synthetic test`, степенью **«Не размечено»**.
- Проверь поиск по названию `Fundus` и источнику `Synthetic`.
- Открой карточку, измени описание, сохрани и затем удали.
- Загрузку изображений проверяй только на открытых / синтетических изображениях, на использование которых есть разрешение.

## 7. Остановить

В окне `docker compose up` нажми `Ctrl+C`, затем по желанию `docker compose down`. Не используй `down -v`, если хочешь сохранить данные.

## Если есть ошибки

- `docker is not recognized`: Docker Desktop не установлен или не запущен.
- `port is already allocated`: порт 3000 или 8000 занят другой программой.
- `cannot connect to Docker daemon`: дождись запуска Docker Desktop.
- Ошибка `npm` / загрузки образов: проверь подключение к сети; первый запуск скачивает зависимости.
- Если уже был установлен первоначальный MRI-проект, используй **новую базу/том Docker**; миграции несовместимы с прежней MRI-базой.
