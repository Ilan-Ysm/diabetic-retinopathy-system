# Diabetic Retinopathy Research Web App — Stage 1

Учебный прототип веб-системы для каталогизации **изображений глазного дна** при исследовании методов автоматического обнаружения диабетической ретинопатии.

**Текущий статус:** работают учётные записи, CRUD, поиск по названию и датасету, фильтрация по подтверждённой степени ДР, пагинация и загрузка JPG/PNG. **Модель ИИ не обучена и не подключена; предсказания не выполняются.** Не использовать для диагностики.

## Требования

- Docker Desktop с Docker Compose, свободные порты 3000 и 8000.
- Для редактирования кода: PyCharm (Python) и Node.js (Next.js).

## Запуск из корня проекта

1. Скопируйте `.env.example` в `.env` (Windows PowerShell: `Copy-Item .env.example .env`).
2. Поменяйте `POSTGRES_PASSWORD` и `SECRET_KEY` в `.env`. Файл `.env` не коммитьте.
3. Запустите:

```bash
docker compose up --build
```

4. Откройте http://localhost:3000 и зарегистрируйте пользователя.
5. Откройте http://localhost:8000/docs для Swagger API. Для вызовов `/scans` нужна авторизация: сначала `/auth/login`, затем Authorize.
6. Для наполнения 30 синтетическими метаданными (без изображений и клинических меток):

```bash
docker compose exec backend python -m scripts.seed
```

Для остановки: `docker compose down`. Не используйте `docker compose down -v`, если нужно сохранить данные.

## Возможности и данные

| Поле | Значение |
|---|---|
| `title` | Название записи |
| `dataset` | Источник / датасет |
| `ground_truth_grade` | Подтверждённая метка: 0, 1, 2, 3, 4 или `null` |
| `eye_side` | `left` / `right` / `null` |
| `predicted_grade` | `null` до подключения обученной модели |
| `confidence` | `null` до подключения модели |

API: `GET /scans`, `GET /scans/{id}`, `POST /scans`, `PATCH /scans/{id}`, `DELETE /scans/{id}`, `POST /scans/upload`, `GET /scans/{id}/image` (с авторизацией). Автоматическая документация: `/docs`.

### Тесты

```bash
cd backend
uv sync --group dev
uv run pytest -q
uv run ruff check .
```

Тесты используют SQLite в памяти. PostgreSQL создаётся миграцией Alembic при запуске Docker. В текущем starter-проекте сохранён пример GitHub Actions для CI.

### Важно

- Только открытые, собственные обезличенные или синтетические данные с соответствующими разрешениями; не загружайте изображения реальных пациентов или иные персональные сведения в этот исследовательский прототип.
- Изображения доступны авторизованным пользователям приложения; для работы с реальными медданными понадобятся дополнительное разграничение доступа и меры защиты.
- Эта версия рассчитана на **новую чистую базу**. Не применяйте её миграцию к базе исходного проекта MRI.
- Степени ДР 0–4 в системе означают внешнюю разметку из датасета, а не медицинское заключение.
