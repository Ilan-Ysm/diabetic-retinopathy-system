# Архитектура исследовательского прототипа

Браузер → Next.js (порт 3000) → FastAPI (порт 8000) → PostgreSQL 17. Docker Compose запускает все три сервиса. `GET /scans/{id}/image` доступен по JWT; Next.js проксирует изображения через `/media/{id}` с серверной cookie. Разрешены только демонстрационные, синтетические и открытые изображения без персональной информации.

Слои FastAPI: `models.py` (таблицы), `schemas.py` (валидация), `service.py` (SQL/бизнес-логика), `router.py` (HTTP API). Alembic управляет схемой PostgreSQL. `/docs` предоставляет Swagger UI. JWT позволяет регистрироваться и редактировать только свои записи (или администратору).

Объект `Scan`: `ground_truth_grade` — внешняя подтверждённая разметка, `predicted_grade` — зарезервированное поле будущей модели, сейчас всегда NULL. Загрузка сохраняет файл, но **не выполняет классификацию**.

База использует миграцию `001_initial_dr` для чистой установки; миграции старого MRI-проекта удалены, совместимость со старой БД не предполагается.
